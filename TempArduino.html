💻 Mostra sketch Arduino C++ (LM35 + LiquidCrystal_I2C) 
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Display LCD 16x2 su bus I2C (indirizzo standard 0x27)
LiquidCrystal_I2C lcd(0x27, 16, 2);
const int PIN_LM35 = A0; // Uscita analogica LM35 (10 mV/°C)

void setup() {
  lcd.init();
  lcd.backlight();
}

void loop() {
  int valoreADC = analogRead(PIN_LM35);
  // Conversione ADC 10-bit (5V = 5000 mV) -> Temperatura in °C
  float tensione_mV = (valoreADC / 1023.0) * 5000.0;
  float tempC = tensione_mV / 10.0;

  lcd.setCursor(0, 0);
  lcd.print("Temp: ");
  lcd.print(tempC, 1);
  lcd.print(" C   ");

  lcd.setCursor(0, 1);
  if (tempC < 0.0)        lcd.print("STATO: SOLIDO   ");
  else if (tempC == 0.0)  lcd.print("FASE: FUSIONE   ");
  else if (tempC < 100.0) lcd.print("STATO: LIQUIDO  ");
  else if (tempC == 100.0)lcd.print("FASE:EBOLLIZIONE");
  else                    lcd.print("STATO: AERIFORME");

  delay(250);
}

Cosa sta succedendo? Riscaldamento del ghiaccio

Sotto lo zero, l'acqua si trova allo stato solido. Le molecole sono strettamente legate tra loro in una struttura ordinata (reticolo cristallino) e possono soltanto vibrare sul posto. Fornendo calore, la temperatura sale e le molecole vibrano sempre più velocemente.

💡 Concetto Chiave — Calore Latente e Sosta Termica:
Anche se il fornello continua a fornire energia, la temperatura resta ferma! Tutto questo calore (detto calore latente) non serve ad agitare più velocemente le molecole, ma viene usato come "energia di rottura" per spezzare i legami che le tengono unite.
